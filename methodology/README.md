# Methodology Documentation

This folder contains methodology documentation for the ForesightGraph project. These documents define the research approach, evaluation metrics, and experimental protocols used in the methodology layer.

## Documentation Files

### Core Methodology Documents
- **hypotheses.md**: Research hypotheses and assumptions guiding the methodology
- **metric_definitions.md**: Definitions of evaluation metrics used in experiments
- **baseline_comparison.md**: Comparison protocols against baseline approaches
- **benchmark_protocol_v0.1.md**: Initial benchmark protocol for methodology evaluation
- **acceptance_criteria.md**: Minimal acceptance criteria for methodology validation

### Related Resources
- **evals/golden_sets/**: Golden sets for evaluation and testing
- **evals/multi_hop_questions/**: Multi-hop question datasets
- **evals/rag_vs_wiki_benchmark/**: RAG vs Wiki baseline comparison benchmarks
- **reports/methodology/**: Methodology benchmark reports and findings

## Notes

This documentation is for research methodology only and does not contain executable automation.

Metrics and benchmarks are research indicators, not absolute truth. They represent initial research gates for methodology validation, not final performance requirements.
